# **App Name**: AI4All Training Hub

## Core Features:

- Course Overview Dashboard: Display a landing page with an overview of the 8-week AI/ML course, powered by AI4All. It will include links to course modules, external resources, and future dashboards.
- Weekly Modules Display: Display weekly module content within cards, with links to detailed content. Each module provides a structured learning path for the 8-week duration.
- Resource Links: Provide a curated list of external resources (YouTube videos, articles, documentation) relevant to each module. It allows users to supplement their learning with external content.

## Style Guidelines:

- Primary color: A gradient from blue-50 to indigo-100 for a calm and professional feel.
- Accent color: Teal (#008080) for interactive elements and highlights, providing a modern touch.
- Use a clean, card-based layout with ample spacing to improve readability and visual appeal, leveraging ShadCN components.
- Subtle animations (e.g., using Framer Motion) for transitions and interactions to enhance the user experience.
- Use consistent and modern icons to represent different sections and actions, improving visual communication.

## Original User Request:
Using Gemini a comprehensive online training course content on Artificial Intelligence (AI) and Machine Learning (ML) for a duration of 8 weeks was generated. The course should progress from a beginner/introductory level to an intermediate level.

Target Audience: The course is designed for a group of individuals, largely with an engineering background, who possess a basic understanding of AI, ML, and data engineering. Their primary goal is to become employable in this field, secure training contracts, work as a team on AI integration projects for Small and Medium-sized Enterprises (SMEs), and potentially act as Virtual Assistants (VAs) managing AI-based project workflows on behalf of clients.
